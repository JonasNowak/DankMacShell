# Agent Guidelines (`AGENTS.md`)

## Mandatory Preview Before Commits and Outward-Facing Text
- **Always show a preview first:** Before creating any git commit, tag, push, release, or modifying/publishing any outward-facing text (including commit messages, `README.md`, public documentation, changelogs, PR descriptions, or user-visible copy), you **MUST** display the exact proposed text and/or diff preview to the user first and wait for their explicit confirmation before executing the action.
